Set up Google sign-in (one time)
  1. Open console.cloud.google.com, create a project, then in APIs & Services → Library enable Google Drive API.
  2. In OAuth consent screen choose External, fill in the app name and your email, and add your Google account (and friends') under Test users.
  3. In Credentials → Create credentials → OAuth client ID choose Web application. Under Authorized JavaScript origins add the address you open this page from (for example https://yourname.github.io or http://localhost:8080).
